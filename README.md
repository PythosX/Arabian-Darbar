# Arabian Darbar — Cinematic Restaurant Website

A premium React + Vite restaurant experience for **Arabian Darbar — Haji Sageer Sahab**, designed around Arabian × Indian × Mumbai visual storytelling.

## Features

- Cinematic hero landing experience
- Arabian ornamental visual system
- GSAP + ScrollTrigger motion
- Responsive navigation
- Story-driven restaurant introduction
- Mumbai × Arabian visual section
- Real-image-first food experience
- Food image hover zoom/reveal behavior
- Dedicated horizontal Mandi storytelling section
- Interactive menu category filters
- Menu item cinematic modal
- Editorial food gallery
- Platform rating section with centralized dynamic data
- Swiggy and Zomato ordering CTAs
- Verified-location information structure
- Opening-hours component
- Artistic location/map treatment
- Custom desktop cursor
- Magnetic-feeling interactive buttons
- Responsive mobile layout
- Reduced-motion accessibility support
- Centralized restaurant/menu/dish/rating data
- Performance-friendly transform/opacity animation approach
- PythosX developer credit

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Add Supplied Images

Copy the restaurant and food images into:

```text
public/assets/restaurant/
public/assets/food/
public/assets/menu/
public/assets/illustrations/
public/assets/textures/
```

The current code includes intentional image placeholders/fallbacks so the site remains usable before the supplied image files are copied into the project.

Recommended filenames used by the starter:

```text
public/assets/food/mutton-korma.jpg
public/assets/food/chicken-mandi.jpg
public/assets/food/mutton-mandi.jpg
```

## Data

Business information is centralized in:

```text
src/data/restaurant.js
```

Menu information is centralized in:

```text
src/data/menu.js
```

Dish information is centralized in:

```text
src/data/dishes.js
```

Before publishing, replace placeholder/unavailable menu prices with the exact prices from the supplied menu photographs and/or a current verified menu source.
